# 1.2-beta5

本次版本覆盖 beta4 之后的所有改动：新增 mt6797（Helio X20/X25）方案、G79 外放无声根治、auto 模式增强、移植信息自动读取，以及 UI 交互优化。

## 新增

- **新增 mt6797（Helio X20/X25）方案**：kernel 3.18、arm64 双架构（lib + lib64）全套驱动替换（kernel / fstab / init / firmware / mddb / Mali / 音频 / TFA 功放 / WiFi / RIL / camera 等约 30 项）
- **auto 模式增强**：补充 lib64 / egl / TFA 目录组，HAL 扫描扩为 4 个 hw 目录（lib | lib64 | vendor/lib | vendor/lib64），硬件库关键词增加 tfa 等
- **移植信息自动读取**：移植时自动打印底包 / 移植源的内核版本与 GCC 版本（支持从 32 位自解压 zImage 提取）、boot 头参数、Android 版本、SDK、芯片平台、系统架构、Vendor 目录、文件总数
- **移植条目三态全选**：标题右侧全选框，部分选中显示“-”，点击全选“✓”，再点全空

## 修复

- **G79 外放无声根治**：补全音频 HAL / TFA 功放 / audio 配置双架构替换，解决移植后外放无声音的问题
- **移植条目滚轮失效**：鼠标悬停在复选框上无法滚动（事件未传递），及滚动步长过大直接跳底的问题
- **既有方案缺项补齐**：G79 / auto 的 audiodriver、camera、wifi、bluetooth 等替换组补 lib64 双架构；auto 模式补 init 替换

## 优化

- **日志结构化**：树形缩进展示双端设备信息，屏蔽底层解包工具的英文噪音；API 版本检测支持 Android 4.4–7.1 映射
- **方案改名与排序**：未列芯片（同平台自动识别）移至倒数第二，仅移植内核（只输出 boot）移至最底
- **UI 滚动体验**：滚轮按行步进（每格 2 行），高精度滚轮自动放大

## 注意事项

- 面向 **Android 7.1.2 及更低版本**（无 VNDK）的老设备；Android 8.0+（有 VNDK / Treble）建议直接刷 GSI
- 仅支持 **同平台 / 同芯片系列** 之间移植，跨平台会导致驱动不兼容、无法开机
- 仅移植内核（kernel-only）模式只输出 boot.img，不处理 system
